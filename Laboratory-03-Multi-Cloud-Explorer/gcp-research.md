### Google Cloud Platform (GCP) 

### Brief Overview

Google Cloud is Google's cloud computing platform. It provides services for computing, storage, databases, analytics, artificial intelligence, machine learning, networking, security, and application development. Google Cloud uses the same global infrastructure that supports Google's large-scale online services.

Official website: https://cloud.google.com/

### Global Infrastructure

Google Cloud infrastructure is organized into regions and zones. The physical machines that run Google Cloud services are located in data centers and logically organized into these geographic locations. This structure helps organizations select locations based on latency, availability, data requirements, and application architecture.

Google Cloud also provides global networking and distributed infrastructure that can support applications and users in multiple geographic locations.

Official documentation:

https://docs.cloud.google.com/docs/overview

https://cloud.google.com/about/locations

### Cloud Management Console

The Google Cloud console is a web-based graphical interface for managing Google Cloud projects and resources. It can be used to create, deploy, scale, and monitor infrastructure and applications. Administrators can also manage IAM policies, billing accounts, and governance activities.

Official console: https://console.cloud.google.com/

Official documentation: https://docs.cloud.google.com/docs/get-started/interact-with-resources

 ### Four Core Services

1. Compute Engine

Compute Engine provides virtual machines that run on Google's cloud infrastructure.

Service page: https://cloud.google.com/products/compute

2. Cloud Storage

Cloud Storage provides scalable and durable object storage for files, backups, media, archives, and application data.

Service page: https://cloud.google.com/storage

3. BigQuery

BigQuery is Google's managed data analytics and data warehousing platform for analyzing large datasets.

Service page: https://cloud.google.com/bigquery

4. Cloud Run

Cloud Run is a managed platform for running containerized applications and services without managing the underlying server infrastructure.

Service page: https://cloud.google.com/run

### Three Advantages

Advanced data analytics and AI capabilities – Google Cloud provides strong services for large-scale analytics, machine learning, and AI workloads.

Global infrastructure and networking – Organizations can use Google's worldwide infrastructure and network to support distributed applications.

Multicloud and open-source support – Google Cloud supports technologies such as Kubernetes and can be used in hybrid and multicloud architectures.

### Typical Enterprise Use Cases

Data warehousing and large-scale analytics
