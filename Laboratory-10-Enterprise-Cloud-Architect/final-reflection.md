# Final Reflection
## Mission 10: The Enterprise Cloud Architect

Throughout my journey in CCM101 – Cloud Computing, from Mission 1 to Mission 10, I gained valuable knowledge and practical experience in understanding cloud computing, Linux system administration, virtualization, networking, and cloud infrastructure management.

At the beginning of this course, I had limited knowledge of how cloud environments work and how servers are configured and managed. As I completed each laboratory activity, I gradually developed my understanding of cloud computing concepts and learned how different technologies work together to build and maintain a functional system.

One of the most important things I learned was how to work with Linux and Ubuntu Server. I became more familiar with using terminal commands, managing files and directories, configuring services, and performing basic server administration. I also learned about virtualization and how virtual machines provide an environment for running and managing servers.

In Mission 10, I was able to apply the knowledge I gained from the previous activities by designing and deploying a multi-tier cloud application using Docker and Docker Compose. I learned how containers communicate with each other, how persistent volumes protect important database information, and how infrastructure can be managed through configuration files. I also gained a better understanding of server security by configuring UFW, applying a default-deny policy, and allowing only the necessary network ports.

Another important lesson was automation. Creating a Bash script and scheduling it through Cron helped me understand how repetitive administrative tasks can be performed automatically. This showed me the importance of automation in maintaining system reliability, monitoring operations, and protecting data through regular backups.

Although completing the activities presented challenges, they helped me become more patient, resourceful, and confident in troubleshooting technical problems. I realized that building cloud infrastructure requires more than simply following commands. It requires planning, understanding how different components work together, identifying possible risks, and finding appropriate solutions.

Overall, my journey from Mission 1 to Mission 10 has strengthened my knowledge and skills in cloud computing, DevOps, and system administration. This final mission taught me that becoming a cloud architect requires responsibility, critical thinking, continuous learning, and the ability to design secure and reliable systems.

As I move forward, I will continue improving my technical skills and exploring more advanced cloud technologies. I am grateful for the knowledge and experiences I gained throughout this course because they have given me a stronger foundation for future projects and my career in Information Technology.
