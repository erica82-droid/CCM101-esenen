# Laboratory 05 – Cloud Data Engineer

## Mission Overview

In this laboratory activity, I deployed an S3-compatible Object Storage server using MinIO and Docker. The purpose of the activity was to create a proof-of-concept storage environment for a photo-sharing application that needs to store large amounts of user-uploaded images.

## Objectives

* Differentiate between Block, File, and Object Storage.
* Deploy an S3-compatible Object Storage server using MinIO and Docker.
* Access the MinIO Web Console through port forwarding.
* Create a cloud storage bucket.
* Upload an object to the bucket.
* Document cloud storage operations using Markdown.

## Tools Used

* KillerCoda Playground
* Ubuntu
* Docker
* MinIO
* GitHub
* Web Browser
* Markdown

## Skills Learned

Through this laboratory activity, I learned how to deploy a containerized object storage service using Docker. I also learned the differences between block, file, and object storage and how to create a bucket and upload objects using the MinIO Web Console. Additionally, I practiced using Linux commands, Docker environment variables, port forwarding, and Markdown documentation.
