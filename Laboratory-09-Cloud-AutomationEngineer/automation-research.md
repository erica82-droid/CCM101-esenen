# Research: The Language of Automation

## 1. Bash Script

A Bash script is a file containing a series of commands that the Linux operating system can execute automatically in sequence. The line `#!/bin/bash`, called the shebang, tells the system to use the Bash shell to interpret and run the commands in the script.

## 2. Variables

Variables are used to store values, such as folder paths, filenames, or configuration settings, so programmers do not have to type the same information repeatedly. For example, using `$BACKUP_DIR` to store a backup folder path makes a script easier to read, update, and maintain because the path only needs to be changed in one place.

## 3. Cron Job

A cron job is a scheduled task in Linux that automatically runs a command or script at a specific time or at regular intervals. It is essential for cloud operations because it can automate repetitive tasks, such as backing up files, cleaning temporary data, and monitoring systems, without requiring someone to run them manually.
