Mission Reflection

Throughout this semester, I learned that cloud computing involves more than just storing files online. It requires automation, security, infrastructure management, and careful planning to build reliable systems.

Automation is critical when managing hundreds of cloud servers because performing tasks manually takes too much time and can lead to human errors. With automation, administrators can execute repetitive tasks, such as backups, software updates, and system monitoring, consistently across many servers. This saves time and helps maintain reliable operations.

However, automation also has potential dangers. A destructive typo in a script scheduled to run on 1,000 servers could delete important files, interrupt services, or cause significant data loss across the entire infrastructure. This is why scripts should be tested in a safe environment, reviewed carefully, and monitored before being deployed widely. Backups and recovery plans are also important.

Writing a Bash script was different from creating a Docker Compose YAML file in Mission 6. Bash uses commands and variables to perform actions step by step, such as creating directories and compressing files. Docker Compose YAML, on the other hand, defines how containers, networks, and services should be configured. Bash focuses on executing tasks, while Docker Compose focuses on describing an application's environment.

From Laboratory 1 to Laboratory 9, my understanding of cloud computing developed from learning basic concepts to understanding how different technologies work together. I learned that cloud computing includes infrastructure, application deployment, networking, security, and automation. Each laboratory helped me appreciate the importance of making systems efficient, scalable, and secure.

The role I enjoyed most was the Infrastructure Engineer because I liked learning how systems are configured, maintained, and automated. Creating a backup script and scheduling it with cron helped me understand how infrastructure tasks can be performed without constant manual intervention. Overall, this semester improved my technical knowledge and showed me the importance of continuous learning, careful testing, and responsible cloud management.
