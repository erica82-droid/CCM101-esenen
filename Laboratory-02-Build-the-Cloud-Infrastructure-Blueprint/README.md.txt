Technical Documentation

## Mission Overview

The mission of this laboratory activity is to document the technical tasks performed while working with cloud infrastructure and Linux systems. The activity focuses on understanding the setup, configuration, management, and use of cloud-based resources while applying basic Linux commands and troubleshooting technical issues.

## Objectives

* Understand the basic concepts of cloud computing and cloud infrastructure.
* Identify the different components used in the laboratory environment.
* Create and manage cloud resources as required by the activity.
* Access and operate a Linux-based system or server.
* Execute essential Linux commands for file, directory, and system management.

## Cloud Infrastructure Components

* **Virtual Machine (VM)** – Provides a virtual computing environment for running applications and services.
* **Cloud Server/Instance** – Hosts the Linux operating system used during the laboratory activity.
* **Virtual Network** – Enables communication between cloud resources.
* **Storage** – Stores files, data, and system information.
* **Security Controls** – Helps manage access to cloud resources and services.
* **Public IP Address** – Allows remote access to the cloud server when needed.

## Tools Used

* **Cloud Platform** – Used to create and manage cloud infrastructure resources.
* **Linux Operating System** – Used as the primary environment for executing commands and performing administrative tasks.
* **Terminal/Command Line Interface** – Used to interact with the Linux system.
* **SSH (Secure Shell)** – Used for secure remote access to the server.
* **Git/GitHub** – Used for version control and maintaining the laboratory documentation.
* **Markdown** – Used to format the README documentation.

## Linux Commands Executed

```bash
pwd
ls
cd <directory>
mkdir <directory_name>
touch <file_name>
cp <source> <destination>
mv <source> <destination>
rm <file_name>
cat <file_name>
sudo apt update
sudo apt upgrade
```

## Skills Learned

* Basic cloud infrastructure management
* Linux command-line navigation
* File and directory management
* Remote server access using SSH
* Basic system administration
* Troubleshooting and problem-solving

## Challenges Encountered

* Understanding the relationship between different cloud infrastructure components.
* Navigating the Linux command-line environment and using unfamiliar commands.
* Managing file paths and permissions correctly.
* Resolving errors caused by incorrect command syntax.
* Establishing a stable connection to the remote server.
* Configuring cloud resource settings.
* Documenting completed tasks clearly and accurately using Markdown.
