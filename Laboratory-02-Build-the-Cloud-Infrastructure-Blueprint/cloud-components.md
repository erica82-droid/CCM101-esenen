# Checkpoint 3 – Cloud Infrastructure Components

## 1. Compute Resources

**Example:** 1 CPU Core, Intel Xeon CPU, 1.9 GiB RAM.

**Purpose:** Provides processing power and memory to run applications.

**Importance:** Cloud computing needs compute resources to process workloads.

**KillerCoda:** The environment uses 1 CPU core and 1.9 GiB of RAM.

## 2. Storage Resources

**Example:** `/dev/vda1` with 19 GB capacity.

**Purpose:** Stores the operating system, applications, and data.

**Importance:** Cloud systems need storage to save files and information.

**KillerCoda:** The main disk has 19 GB total space with 13 GB available.

## 3. Networking Resources

**Example:** IP addresses `172.30.1.2` and `172.17.0.1`.

**Purpose:** Allows communication between systems.

**Importance:** Networking connects cloud services and users.

**KillerCoda:** The Linux environment uses IP addresses for network communication.

## 4. Operating System

**Example:** Ubuntu 24.04.4 LTS.

**Purpose:** Manages hardware and software resources.

**Importance:** The operating system allows cloud applications and services to run.

**KillerCoda:** The environment is running Ubuntu 24.04.4 LTS with kernel version 6.8.0-136-generic.
