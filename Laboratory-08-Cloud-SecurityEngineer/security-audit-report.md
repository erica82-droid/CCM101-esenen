# Security Best Practices

## 1. Principle of Least Privilege (PoLP)

The Principle of Least Privilege means that each user should only have the permissions necessary to perform their assigned tasks. It is important for cloud user accounts because it reduces the risk of unauthorized access, accidental changes, and damage if an account is compromised.

## 2. Attack Surface

The attack surface of a virtual machine refers to all the possible entry points that an attacker could use to gain unauthorized access. These may include open ports, running services, applications, and remote login interfaces, so reducing unnecessary services and closing unused ports helps improve security.

## 3. Default Deny Policy

A Default Deny Policy means that all network traffic is blocked unless it is explicitly allowed by a security rule. This is safer than blocking individual hackers because new or unknown threats may appear at any time, while allowing only trusted and necessary traffic limits unauthorized access.
