# Reflection

This laboratory activity helped me understand the basics of cloud computing, Linux, and GitHub. I learned how to use the KillerCoda Linux environment and perform basic Linux commands such as `whoami`, `pwd`, `hostname`, `mkdir`, `touch`, and `cat`.

I also learned how to create a new Linux user, manage directories and files, and check system information such as the Linux distribution, kernel version, CPU, memory, and disk space.

Another important thing I learned was how Git and GitHub can be used to organize, track, and store project files. Overall, this activity improved my confidence in using the Linux command line and gave me a better understanding of how cloud environments and version control are used in Information Technology.
